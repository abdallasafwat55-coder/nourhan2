اسم المشروع (في package.json): midnight-express-birthday

نوع المشروع: موقع ويب تفاعلي (صفحة واحدة SPA) — هدية / ذكريات رومانسية

================================================================================
1) نظرة عامة — ما هو المشروع؟
================================================================================

هذا موقع ويب شخصي يجمع بين:
  • شاشة افتتاحية (Opening) لعيد ميلاد — كعكة متحركة، كونفيتي، بالونات، صورة.
  • صفحة رئيسية بثيم خيالي (غابة، بيوت فطر، ألوان زرقاء/سماوية) تعرض ذكريات.
  • تجربة سينمائية كاملة (Cinema Experience): شخصيات كرتونية زرقاء تدخل من اليمين،
    تشد شاشة، تجلس، الإضاءة تخفت، يبدأ عرض فيديو أو سلايدشو للصور.

الفكرة: ليس مجرد تصميم ثابت — بل رحلة Motion + Cinematic عند الضغط على
«ابدأ الآن» أو «استعرض».

7) شاشة الافتتاح: src/Opening.tsx
================================================================================

تُعرض عبر createPortal على document.body بـ z-index 99999.

المراحل (Phase):
  • cake      — الشاشة الأولى: كعكة ثلاث طبقات تُبنى بالأنيميشن + شمعة + نص
                «Happy 20th Birthday!» يُكتب حرفاً حرفاً (typewriter).
  • slide     — بعد ~4.2 ثانية: انزلاق للشاشة الثانية (وردي).
  • celebrate — بعد ~5.6 ثانية: بالونات + صورة + «Dina ghanem».
  • finishing — (اختياري) تلاشٍ أبيض — لا يُغلق تلقائياً؛ المستخدم يضغط «تخطي».

مميزات:
  • 80 قطعة كونفيتي متحركة (Framer Motion).
  • 18 نجمة متحركة.
  • 14 بالونة من مجلد public/images/ballon/.
  • صورة رئيسية من /images/g2.jpg في دائرة.
  • أزرار: «Click Here again» (reload)، «Play sound» (/sounds/happy-birthday.mp3).
  • بالونات إضافية من /images/balloons/ (إن وُجدت — المجلد قد يكون فارغاً).

زر «تخطي» أعلى اليسار يستدعي onComplete() → يخفي الافتتاحية ويُظهر الموقع.

8) التجربة السينمائية — مجلد src/cinema/
================================================================================

8.1) cinemaTypes.ts
────────────────────
يُعرّف نوع CinemaStage:
  intro → enter → pull → sit → lightsOff → projector → movie

8.2) CinemaExperience.tsx — المنسّق الرئيسي
────────────────────────────────────────────
Props:
  • open: boolean
  • onClose: () => void
  • slideImages: string[]

عند open = true:
  • يُعاد stage إلى intro.
  • يتحقق HEAD من village-bg.jpg و movie.mp4.
  • يُحمّل (إن وُجدت):
      /audio/pull-screen.mp3
      /audio/projector-on.mp3
      /audio/cinema-ambience.mp3 (loop)

جدول التوقيت التقريبي:
  ┌──────────┬────────────┬────────────────────────────────────────────────┐
  │ الوقت    │ المرحلة    │ ماذا يحدث                                      │
  ├──────────┼────────────┼────────────────────────────────────────────────┤
  │ 0–1 ث    │ intro      │ عنوان «عالمنا السينمائي»                       │
  │ 1 ث      │ enter      │ دخول الشخصيات من اليمين                        │
  │ 3.5 ث    │ pull       │ شد الشاشة + صوت pull (إن وُجد)                 │
  │ 6.5 ث    │ sit        │ جلوس الشخصيات                                  │
  │ 8.5 ث    │ lightsOff  │ تعتيم الإضاءة + طبقة سوداء                     │
  │ 10.5 ث   │ projector  │ بروجكتور + ستائر جانبية + وميض                 │
  │ 12.5 ث   │ movie      │ فيديو أو سلايدشو                               │
  └──────────┴────────────┴────────────────────────────────────────────────┘

عناصر بصرية:
  • خلفية قرية (village-bg أو hero-fantasy احتياطي).
  • شاشة مركزية تُفتح بـ scaleY spring + حبال ذهبية أثناء pull.
  • ستائر gradient يسار/يمين تنزلق عند projector/movie.
  • شعاع بروجكتور (blur cyan).
  • CinemaFlicker — وميض سينمائي أبيض شفاف.

العرض في movie:
  • إن وُجد public/video/movie.mp4 → فيديو autoplay muted loop.
  • وإلا → CinemaSlideShow بصور g1-g6 كل 2.6 ثانية.

أزرار:
  • «تخطي المشهد» — أعلى اليسار → onClose()
  • «متابعة الموقع» — أسفل الوسط (في movie) → onClose()

الشخصيات:
  • CinemaCharacters3D (lazy load) — Canvas Three.js فوق المشهد.
  • BlueCritter.tsx — بديل SVG إن مرّرت pngSrc (غير مستخدم في المسار 3D الحالي).

8.3) CinemaSlideShow.tsx
────────────────────────
يعرض صوراً واحدة تلو الأخرى مع fade + scale خفيف.
intervalMs افتراضي 2800 (في App يُمرَّر 2600).

8.4) CinemaFlicker.tsx
──────────────────────
طبقة بيضاء mix-blend-overlay تومض opacity بسرعة — إحساس بروجكتور قديم.

8.5) CinemaCharacters3D.tsx + ForestCritter3D.tsx
───────────────────────────────────────────────
  • Canvas شفاف (alpha) فوق الصفحة، z-index 38.
  • 3 شخصيات (slot 0, 1, 2) بألوان زرقاء مختلفة.
  • لكل مرحلة cinema: مواضع وأذرع ودوران مختلف (getTargets).
  • useFrame لتحريك ناعم (lerp) بين الحالات.
  • ContactShadows من drei للظل على الأرض.
  • أجزاء الجسم: جذع، رأس، قبعة فطر، عيون، فم، ذراعان منفصلان.

14) قرارات تقنية مهمة
================================================================================

  • React.lazy لـ CinemaCharacters3D — تحميل Three.js عند الحاجة فقط (أداء).
  • fetch HEAD للتحقق من وجود فيديو/خلفية قبل العرض.
  • useReducedMotion في BlueCritter — احترام إعدادات إمكانية الوصول.
  • AnimatePresence من Framer Motion — دخول/خروج ناعم للطبقات.
  • StrictMode في main — تحذيرات تطوير React مزدوجة في dev فقط.
  • noUnusedLocals في tsconfig — أي import غير مستخدم يفشل البناء.

17) استكشاف الأخطاء
================================================================================

  • الشاشة بيضاء:
      - تأكد npm install ثم npm run dev من مجلد المشروع.
      - افتح Console في المتصفح لأخطاء import.

  • الصور لا تظهر:
      - الملفات يجب أن تكون في public/images/ وليس src/.
      - الأسماء حساسة لحالة الأحرف على Linux.

  • الشخصيات لا تظهر في المشهد:
      - تحقق أن WebGL مدعوم في المتصفح.
      - انتظر تحميل lazy chunk (شبكة بطيئة).

  • لا صوت:
      - المتصفح يمنع autoplay بدون تفاعل المستخدم أحياناً.
      - ضع ملفات mp3 في public/audio و public/sounds.

  • البناء يفشل:
      - npm run build — اقرأ رسالة TypeScript (متغير/import غير مستخدم).
